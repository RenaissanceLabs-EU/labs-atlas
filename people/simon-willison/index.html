About

Willison co-created the Django web framework, created Datasette and the LLM command line tool, and has written a blog since 2002. Recent writing focuses on LLMs, coding agents and AI security, including the terms prompt injection and the lethal trifecta.

Co-creator of the Django web framework with a Wikipedia article; creator of Datasette and the LLM command line tool; his blog is a widely read source on LLMs, and he coined the term prompt injection.
