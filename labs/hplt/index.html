About

High Performance Language Technologies is a three-year EU-funded project that started in September 2022. It is coordinated by Charles University in Prague and brings together five universities, two high-performance computing centers and a private NLP company.

Its first release covered monolingual data in 75 languages at 5.6 trillion tokens and parallel data in 18 language pairs. The second release reached 7.6 trillion tokens in 193 languages and 380 million parallel sentences in 51 pairs, distributed under the CC0 license on Hugging Face and its website.

Mission and ambitions

To provide open multilingual datasets, translation models and tools for training language models at scale.

Milestones

  1. 2022

    Project starts

    The EU-funded HPLT project began in September 2022 under Charles University.

  2. 2022

    OpusCleaner

    A web interface for cleaning machine translation training data was published.

  3. 2024

    First data and model release

    HPLT published version 1 datasets and models, described at EAMT 2024.

  4. 2024

    HPLT-MT models

    Configuration and scripts for HPLT translation model releases were published.

  5. 2025

    HPLT v2 data release

    The second release of cleaned monolingual and parallel data under CC0 was described at MT Summit 2025.
