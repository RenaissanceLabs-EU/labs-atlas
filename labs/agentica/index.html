About

Agentica is an open-source effort from the Sky Computing Lab at UC Berkeley. It aims to make reinforcement learning techniques for language models and agents widely available, with core contributors Michael Luo and Sijun Tan and a group of student contributors.

The project released DeepScaleR in February 2025, a 1.5B model trained with distributed reinforcement learning for math reasoning. In July 2025 it published DeepCoder, a 14B code reasoning model, the rLLM framework for training agents with reinforcement learning, and DeepSWE, a 32B software engineering agent.

Its advisors are Li Erran Li, Raluca Ada Popa and Ion Stoica. The project site notes that Agentica is becoming a startup named Peano AI.

Mission and ambitions

Agentica states that it wants to democratize reinforcement learning for language models and to build scalable systems for LLMs and agents.
