About

Gorilla is a UC Berkeley research project led by Shishir G. Patil, Tianjun Zhang, Xin Wang and Joseph E. Gonzalez. It produced Gorilla LLM, an open-source model that invokes API calls, and a paper posted as arXiv 2305.15334.

Related releases include OpenFunctions v2, a 6.91B-parameter function-calling model, RAFT for retrieval-aware fine-tuning, GoEX, a runtime for executing LLM-generated actions with undo and damage confinement, and the Berkeley Function-Calling Leaderboard, which covers about 2,000 question-function-answer pairs across Python, Java, JavaScript and REST.

Mission and ambitions

Gorilla aims to let language models use tools and APIs reliably, and to give the community open models and benchmarks for measuring that ability.
