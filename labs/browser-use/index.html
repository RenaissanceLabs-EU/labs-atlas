About

Browser Use began as an open-source Python library that lets language-model agents control a web browser, built by Magnus Müller and Gregor Žunič, who met during master's studies at ETH Zurich. It joined Y Combinator's Winter 2025 batch.

The company raised a 17 million dollar seed round led by Felicis in March 2025. Today it offers hosted web agents, stealth cloud browsers and Browser Harness, a free open-source tool for coding agents, with enterprise options such as on-premises browsers and an EU cloud in Frankfurt.

Mission and ambitions

The company aims to let AI agents use the web reliably.
