About

Princeton NLP is the natural language processing research group at Princeton University. Its GitHub organization hosts widely used research code and its Hugging Face organization hosts models and datasets.

The group's SWE-bench benchmark, published at ICLR 2024, tests whether language models can resolve real GitHub issues and became a standard evaluation for coding agents. SimPO, presented at NeurIPS 2024, is a reference-free preference optimization method, and Tree of Thoughts (NeurIPS 2023) is a deliberate problem-solving framework for language models.

Karthik Narasimhan is among the authors of SWE-bench; Danqi Chen also leads work in the group.

Mission and ambitions

The group studies how language models learn, reason and act, and releases the resulting benchmarks, methods and code so that other researchers can reproduce and extend them.
