About

Mozilla.ai is a distributed company backed by the Mozilla Foundation that builds open-source AI products and infrastructure. Its GitHub organization dates from April 2023.

Its tools include any-llm, a single interface to many model providers, any-agent for running and evaluating agent frameworks, any-guardrail, mcpd, encoderfile and the Lumigator evaluation platform. It also hosts llamafile, the project that packages a model as one executable. Its newer products are Otari, an open-source governance layer for AI agents, and Octonous.

The team values open foundations and keeps humans in charge of outcomes; the code is largely released under Apache 2.0.

Mission and ambitions

Mozilla.ai builds open-source AI products and infrastructure that give people and organizations more choice, transparency and control.

Milestones

  1. 2023

    Mozilla.ai GitHub organization

    The public organization was created in April 2023.

  2. 2023

    llamafile repository

    The llamafile project, which bundles a model and runtime into one executable, was created in September 2023 and is now hosted under mozilla-ai.

  3. 2024

    Lumigator

    A platform for evaluating language models, first published in March 2024.

  4. 2025

    any-agent

    A single interface for using and evaluating different agent frameworks, created in March 2025.

  5. 2025

    any-llm

    A unified interface to LLM providers, created in July 2025.

  6. 2025

    encoderfile

    A tool to distribute and run transformer encoders as a single file, created in October 2025.
