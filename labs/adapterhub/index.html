About

AdapterHub began in 2020 as a framework for sharing and composing adapters, small sets of added weights that stand in for full fine-tuning of a pretrained model. The original paper by Pfeiffer and colleagues was presented at EMNLP 2020, and the GitHub organization was created in April 2020.

In November 2023 the project released the unified Adapters package, replacing the earlier adapter-transformers fork, with a library paper at EMNLP 2023. The library is released under the Apache 2.0 licence and had about 2,800 GitHub stars in 2026.

Version 1.2.0, announced in May 2025, added a plugin interface for attaching adapter functionality to nearly any Transformer model. The project is run by researchers associated with TU Darmstadt and serves practitioners who need to adapt large models cheaply.

Mission and ambitions

AdapterHub aims to make parameter-efficient and modular transfer learning easy to use, share and combine. It treats adapters as reusable components that the community can publish and compose.
