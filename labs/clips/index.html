About

CLiPS is the computational linguistics and psycholinguistics research centre at the University of Antwerp, with a GitHub organization created in 2011.

Pattern, by Tom De Smedt and Walter Daelemans, is a BSD-licensed Python package for web mining and NLP with Dutch modules, described in a JMLR 2012 paper. The repository holds about 8,800 stars.

The group also released the multilingual FAQ dataset MFAQ and Dutch embedding models.

Mission and ambitions

CLiPS develops computational models of language and shares software and datasets, with attention to Dutch.
